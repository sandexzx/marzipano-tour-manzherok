# Манжерок: тур повышенной детализации (8К, WebP)

**Опубликованный адрес:** https://sandexzx.github.io/marzipano-tour-manzherok/webp-hi-res/

Основной тур остаётся по https://sandexzx.github.io/marzipano-tour-manzherok/. Его код, браузерные JPEG и маршруты не изменены. Экспериментальный JPEG-hi-res удалён; дополнительная версия публикуется только в формате WebP.

## Локальный запуск

Из корня репозитория:

```bash
python3 -m http.server 8082 --bind 127.0.0.1
```

- Высокая детализация: http://127.0.0.1:8082/webp-hi-res/
- Основной тур: http://127.0.0.1:8082/

Для сравнения открывайте одинаковые точки, направление камеры и масштаб. При первом показе и после приближения дождитесь загрузки подробных тайлов. Это исходные архитектурные рендеры: нейросети и искусственная резкость не применяются.

## Изображения и загрузка

- Исходные 37 панорам: equirectangular 8192×4096 из локального `archive/final-0710/0710 рендер.zip`.
- Проекция: FFmpeg `v360`, RGB24, Lanczos; порядок кубических граней `frblud`.
- Четыре уровня: грани 512, 1024, 2048 и 4096 пикселей.
- Тайлы: 512×512, WebP `quality=95`, `method=6`, `lossless=False`.
- Путь: `tiles/{point}/{level}/{face}/{row}/{column}.webp`.
- Количество: 510 тайлов на точку, 18 870 на весь тур.
- Маленькие WebGL-текстуры обходят ограничения на загрузку одной панорамы 8192×4096. Уровень выбирается по окну, масштабу и devicePixelRatio; неактивные сцены освобождают текстуры после перехода.

Кубические грани 4096 сохраняют угловые детали исходников с запасом при перепроецировании. Более крупная выходная сетка не создаёт информации, отсутствующей в оригинальном рендере. WebP сжат с потерями: разрешение сохранено, пиксели могут отличаться от исходника.

### Размер опубликованного набора

| Набор | Размер изображений |
|---|---:|
| Предыдущий JPEG-hi-res (удалён) | 1 112 940 525 байт |
| Опубликованный WebP-hi-res | 575 205 914 байт |

Экономия — 48,3%. На этапе выбора формата PSNR по 222 фрагментам относительно JPEG составил 46,00 dB; WebP-вариант визуально одобрен. Эти метрики не являются гарантией пиксельной идентичности.

Весь опубликованный сайт вместе с основным туром, общими ресурсами и документацией занимает около 637 МБ. Это ниже лимита GitHub Pages в 1 ГБ с запасом около 363 МБ. ZIP и промежуточный JPEG-hi-res не публикуются.

## Подготовка из оригиналов

Зависимости: Python 3, Pillow с WebP, FFmpeg с `v360`. npm-зависимости отсутствуют.

```bash
python3 webp-hi-res/tools/prepare-tiles.py
# Только выбранные точки:
python3 webp-hi-res/tools/prepare-tiles.py --points 1 19
# Другая папка оригинальных 1.jpg … 37.jpg или ZIP:
python3 webp-hi-res/tools/prepare-tiles.py --source /path/to/originals
# Полное повторное построение:
python3 webp-hi-res/tools/prepare-tiles.py --force
```

Уже одобренные WebP-изображения перенесены без повторного сжатия. Для воспроизводимости подготовщик воспроизводит прежний JPEG→WebP процесс: после перепроецирования и нарезки отдельный тайл кодируется JPEG quality=95, 4:4:4 **в памяти**, затем декодируется и сохраняется WebP. Промежуточная JPEG-пирамида на диске больше не нужна. В манифестах первого набора сохранено историческое происхождение из JPEG, включая хеш старого JPEG-манифеста.

Готовые точки пропускаются по SHA-256 исходной панорамы, параметрам и количеству тайлов. Каждая точка сначала строится во временной папке, затем заменяет свой опубликованный каталог. Изображения основного тура не затрагиваются.

## Проверки

```bash
node --test tests/tour.test.cjs
python3 webp-hi-res/tests/test_tiles.py
# При работающем сервере, Node 22 и Google Chrome:
CDP_PORT=9226 node webp-hi-res/tools/smoke.mjs
# Проверка опубликованного варианта:
TOUR_URL=https://sandexzx.github.io/marzipano-tour-manzherok/webp-hi-res/ \
  CDP_PORT=9226 node webp-hi-res/tools/smoke.mjs
```

Python-тест проверяет ориентацию кубических граней по синтетической панораме мировых направлений и полное декодирование всех 18 870 WebP, структуру уровней, размеры и суммарный объём.

Браузерный тест проверяет все 37 точек и видимые тайлы максимального уровня, шесть граней (включая потолок и пол), высокий devicePixelRatio, переходы, лестницы, планы и мобильный интерфейс. Ошибки HTTP и JavaScript приводят к провалу. Скриншоты сохраняются локально и исключены из Git.

## Публикация

Каталог `webp-hi-res/tiles/` включён в Git. GitHub Pages публикует корень ветки `main`; отдельной сборки или внешнего хранилища не требуется. Оригинальные ZIP остаются локальными. Служебные скриншоты, `__pycache__` и временные каталоги подготовки исключены через `webp-hi-res/.gitignore`.

Интерфейс использует общие `../tour.js`, `../style.css`, `../vendor/` и планы из `../assets/`. Локальный `index.js` — самостоятельная копия интерфейса с кубической геометрией и WebP-источником. Дополнительный тур не изменяет адрес или ресурсы основного.
