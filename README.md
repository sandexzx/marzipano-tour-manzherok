# Манжерок — виртуальный тур

**Открыть тур:** https://sandexzx.github.io/marzipano-tour-manzherok/

Веб-тур на Marzipano: 37 панорам, два этажа, стрелки переходов и интерактивные планы. Работает на компьютере и телефоне. Все ресурсы размещены в репозитории, без внешних CDN и аналитики.

## Управление

- Перетаскивание — осмотр, колёсико или жест масштабирования — масштаб.
- Стрелки — переход к соседней точке; переходы на другой этаж подписаны и выделены коричневым.
- Боковая карточка — кнопки выбора этажа и список помещений. На телефоне карточка превращается в компактную верхнюю панель.
- Список помещений поддерживает стрелки клавиатуры, Home/End, Enter, Escape и поиск по первым буквам названия.
- «План этажей» — переход по номеру на чертеже; текущая точка выделена зелёным. Карточка, список и план оформлены в едином светлом архитектурном стиле.
- «Весь план» — полный чертёж, включая ангар (точка 16). Повторное нажатие возвращает увеличенные помещения.

## Локальный запуск

```bash
python3 -m http.server 8082 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8082/. Нужен современный браузер с WebGL. Сборка и установка npm-зависимостей не требуются.

## Структура

- `index.html`, `index.js`, `style.css` — интерфейс, панорамы и навигация.
- `tour.js` — названия, координаты точек на планах и направления переходов.
- `assets/` — панорамы и рабочие планы.
- `tools/prepare-assets.py` — подготовка браузерных копий из финальных рендеров (Pillow).
- `tests/tour.test.cjs`, `tools/smoke.mjs` — проверка маршрутов и браузерный тест.
- `vendor/` — Marzipano 0.10.2, авторство и лицензии библиотеки и её зависимостей.
- `.nojekyll` — статическая публикация без обработки Jekyll.

GitHub Pages публикует корень ветки `main`. Отдельного workflow сборки нет. ZIP, распакованные исходники, локальный архив и служебные изображения исключены из Git.

## Исходные данные и точность

Использованы финальные рендеры из `0710 рендер.zip`: точки 1–37 без перенумерации. Первый этаж — 1–18, второй — 19–37. Оригиналы 8192×4096 сохранены локально в `archive/final-0710/`; прежние исходники — в `archive/legacy/`; браузерные копии уменьшены до 4096×2048, JPEG quality=90, для совместимости с WebGL и снижения времени загрузки.

Маршруты перенесены из инструкции от 07.10.2026 как направленный граф. Обратные переходы не добавляются автоматически: в частности, нет `9 → 7`, `12 → 9`, `13 → 5`. Неописанные конечные точки получили возвраты `15 → 14` и `18 → 17`; фраза «17 в 18 и обратно» трактуется как `17 ↔ 18` с сохранением возврата `17 → 16`.

**В финальном ZIP нет планов.** Пока используются прежние чертежи с обновлёнными номерами. Координаты, названия и направления стрелок сопоставлены визуально и приблизительно; положение новых точек 17 и 18 особенно нуждается в подтверждении по финальному плану. Это не геодезическая калибровка. Ангар (16, 17) доступен на полном плане.

## Проверки и подготовка

```bash
python3 tools/prepare-assets.py  # исходники: archive/final-0710/ и archive/legacy/1-39/
node --test tests/tour.test.cjs
python3 -m http.server 8082 --bind 127.0.0.1
# В другом терминале; Node 22 и Google Chrome:
node tools/smoke.mjs
```

Браузерный тест загружает все 37 панорам, проверяет переходы, обе лестницы, планы, клавиатуру и мобильный интерфейс. Скриншоты сохраняются локально и не публикуются.

## Права и доступность

Лицензии в `vendor/` относятся только к библиотеке и её зависимостям; они не предоставляют права на архитектурные изображения и планы. Сайт и репозиторий публичны: материалы тура доступны посетителям для скачивания, ограничения доступа нет.
